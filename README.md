# 한국 모바일 트래픽 모니터

대한민국 전국 **16개 광역시·도**, **256개 시·군·구**, **3,559개 행정동(읍·면·동)**, 그리고 **25,435개 ~2.1 km 육각 기지국 셀(확대 시 ~800 m H3 7-분할 초미세 셀 · 약 178,000셀 해상도 등가)** 위에서 **15분 단위(96구간) / 1시간 단위(24구간)** 모바일 통신 트래픽 **변화량**을 WebGL2 GPU 가속으로 실시간 시각화하는 웹 프로그램입니다.

- **라이브 웹 앱 (PC·스마트폰)**: https://knoxxr.github.io/gyeonggi-traffic-map/

## 주요 기능

- **전국 4단계 공간 해상도 + 16개 시·도 퀵 점프 필터**:
  - `초미세 셀 (800 m)`: 확대 시 2.1 km 셀 자동 H3 7-분할 (전국 약 178,000셀 해상도 등가)
  - `기지국 셀 (2.1 km)`: 전국 25,435개 육각 셀 + 180+ 전국 핵심 거점(강남·여의도·판교·해운대·서면·동성로·둔산·세종·광양·거제·제주 등) · 8대 광역권 · 15개 주요 고속도로 축 공간 모델
  - `읍·면·동`: 전국 3,559개 최신 행정동 경계 (`2026.10.01` 기준)
  - `시·군·구` (256개) 및 `시·도` (16개 광역시·도)
- **고성능 그래픽 & 경량 아키텍처**:
  - **WebGL2 GPU 인스턴싱**: 25,435개 육각 셀을 단 1회의 `drawArraysInstanced` 호출(4-삼각형 정육각 메쉬 + 버텍스 셰이더 1D 컬러 램프 + 하드웨어 MSAA)로 60fps 렌더링
  - **3-레이어 분리 캔버스 + 뷰포트 컬링**: GPU 히트맵(`glCanvas`) / 행정 경계·라벨(`vectorCanvas`, 확대 시 뷰포트 AABB 컬링) / 30fps 급변 펄스(`fxCanvas`)를 분리해 불필요한 재렌더링 제거
  - **사전 계산 3차 보간 & Gzip 내장 번들**: 347 KB gzip 압축 데이터를 브라우저 네이티브 `DecompressionStream("gzip")`으로 0.7초 내 초기화, 총 단일 실행 파일 크기 **~640 KB**
  - **32×32 공간 격자 인덱스**: 전국 3,559개 행정동·256개 시군구 호버/클릭 히트 테스트를 O(1)에 처리
- **실시간 KST LIVE & 외부 REST API 자동 폴링**:
  - `LIVE` 모드: 한국 표준시(KST) 1초 동기화 + 3초 주기 실시간 트래픽 미세 변동 시뮬레이션
  - **실시간 API 연동**: 임의의 CORS 지원 JSON API(또는 자체 프록시/Cloudflare Worker) URL과 폴링 주기(5초~5분)를 입력해 전국 행정동·시군구 실데이터를 지도에 자동 반영
- **4가지 변화량/규모 지표 & 2단계 시간 해상도**:
  - `변화율 (Δ%)` / `Δ트래픽 (Mbps·Gbps)` / `일평균 대비 (%)` / `총 트래픽`
  - `15분 단위 (96구간)` / `1시간 단위 (24구간)` + 평일/주말 비교
- **스마트폰 최적화**: 두 손가락 핀치 줌·드래그, 하단 시트 분석 패널, 전국 동·시·거점 즉시 검색, 다크/라이트 모드 자동 적응.
- **실데이터 CSV / JSON 업로드·내보내기**: 업로드한 행정동별 트래픽이 하위 25,435개 2.1 km 셀 및 800 m 초미세 셀에도 비례 반영됩니다.

## 프로젝트 구조

```text
gyeonggi-traffic-map/
├── index.html                        # 완전 자립형 전국 실행 파일 (~640 KB, 브라우저에서 바로 실행)
├── src/
│   └── app.html                      # WebGL2 + 3-레이어 인터랙티브 지도 및 UI 소스 템플릿
├── scripts/
│   ├── build_data.py                 # 전국 3,559 행정동 공유 아크 + 25,435 육각 셀 + gzip 번들 생성기
│   └── build_app.py                  # gzip Base64 인라인 자립형 HTML 번들러
├── data/
│   └── korea_bundle.json.gz          # 전처리·gzip 압축된 전국 토폴로지 + 공간 모델 번들 (~347 KB)
└── raw/
    └── HangJeongDong_ver20261001.geojson  # 대한민국 최신 행정동 원본 경계 (vuski/admdongkor, git 제외)
```

## 실행 및 재빌드 방법

### 1) 바로 실행
`index.html`을 웹 브라우저로 열거나 정적 서버로 실행할 수 있습니다.
```bash
python3 -m http.server 8000
```

### 2) 데이터 전처리 및 재빌드
```bash
python3 scripts/build_data.py
python3 scripts/build_app.py
```

## 실데이터 CSV / API JSON 형식

상단 `실시간 API · 데이터` 버튼을 통해 REST API 자동 폴링 또는 CSV/JSON 업로드를 사용할 수 있습니다.

```csv
adm_cd,sggnm,dongnm,day_type,hour,traffic_gbps
1168064000,강남구,역삼1동,weekday,8,42.80
2635052000,해운대구,중1동,weekday,8,14.35
```

- `adm_cd` (10자리 또는 8자리 행정동코드) 또는 `sggnm` + `dongnm`으로 전국 3,559개 행정동에 자동 매칭됩니다.
- 실시간 API JSON은 `{ "timestamp": "...", "items": [{ "adm_cd": "...", "traffic_gbps": 42.8, "delta_pct": 6.4 }] }` 또는 배열 형식을 지원합니다.

## 키보드 단축키

- `Space`: 시간대 재생 / 일시정지
- `L`: 실시간 KST LIVE 모드 토글
- `←` / `→`: 이전 / 다음 시간 구간 이동
- `+` / `-`: 지도 확대 / 축소
- `R`: 대한민국 전국 전체 보기로 리셋
- `Esc`: 선택 지역 해제 / 모달 닫기
