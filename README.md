# 경기도 초정밀 셀·행정동별 모바일 통신 트래픽 변화량 시각화 프로그램

경기도 전역 **11,286개 1km 육각 기지국 셀(확대 시 385m H3 7-분할 초미세 셀 · 약 79,000셀 해상도 등가)**, **602개 행정동(읍·면·동)**, **47개 시·군·구** 위에서 **15분 단위(96구간) / 1시간 단위(24구간)** 모바일 통신 트래픽 **변화량**을 인터랙티브하게 시각화하는 웹 프로그램입니다.

- **라이브 웹 앱 (PC·스마트폰)**: https://knoxxr.github.io/gyeonggi-traffic-map/

## 주요 기능

- **4단계 공간 초세분화**:
  - `385m 초미세 셀` (확대 시 1km 셀 자동 H3 7-분할, 약 0.13 km²/셀 · 전역 ~79,000셀 해상도)
  - `1km 기지국 셀` (경기도 전역 11,286개 육각 셀 + 129개 역·거점·산단·관광지·고속도로 축 공간 모델)
  - `읍·면·동` (602개 최신 행정동 경계, `2026.10.01` 기준)
  - `시·군·구` (47개 시·군·구)
- **2단계 시간 해상도**: `15분 단위 (96구간: 00:00~23:45)` / `1시간 단위 (24구간)` 전환 + 60fps 부드러운 재생.
- **4가지 변화량/규모 지표 모드**:
  - `변화율 (Δ%)`: 직전 15분/1시간 대비 증감률 (발산형 컬러 스케일: 파랑=감소 / 주황·빨강=급증)
  - `Δ트래픽`: 직전 구간 대비 절대 증감량 (`Mbps`/`Gbps`)
  - `일평균 대비 (%)`: 해당 지역 24시간 평균 대비 현재 시각 편차
  - `총 트래픽`: 절대 모바일 통신 트래픽 규모
- **스마트폰 최적화**: 두 손가락 핀치 줌·드래그 이동, 하단 시트 상세 분석 패널, 거점·역명 즉시 검색(`판교역`, `삼성전자`, `에버랜드`, `동탄` 등).
- **실데이터 CSV / JSON 업로드 지원**: 업로드한 행정동별 트래픽이 하위 11,286개 1km 셀 및 385m 초미세 셀에도 비례 반영됩니다.

## 실행 및 재빌드 방법

### 1) 바로 실행
`index.html`을 웹 브라우저로 열거나 로컬 정적 서버로 실행할 수 있습니다.
```bash
python3 -m http.server 8000
```

### 2) 데이터 전처리 및 재빌드
```bash
python3 scripts/build_data.py
python3 scripts/build_app.py
```

## 실데이터 CSV 업로드 형식

`실데이터 업로드` 버튼을 통해 아래 컬럼 구조의 CSV 또는 JSON을 불러올 수 있습니다.

```csv
adm_cd,sggnm,dongnm,day_type,hour,traffic_gbps
4113565500,성남시분당구,삼평동,weekday,8,28.45
4113565500,성남시분당구,삼평동,weekday,9,35.12
```

- `adm_cd` (10자리 또는 8자리 행정동코드) 또는 `sggnm` + `dongnm`으로 자동 매칭됩니다.
- `day_type`은 `weekday`/`weekend` (또는 `평일`/`주말`)을 지원하며, 생략 시 단일 일자 데이터로 반영됩니다.

## 키보드 단축키

- `Space`: 시간대 재생 / 일시정지
- `←` / `→`: 1시간 이전 / 이후 이동
- `+` / `-`: 지도 확대 / 축소
- `R`: 경기도 전체 보기로 리셋
- `Esc`: 선택 지역 해제 / 모달 닫기
