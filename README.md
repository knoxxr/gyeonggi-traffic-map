# 경기도 행정동별 모바일 통신 트래픽 변화량 시각화 프로그램

경기도 전역 **602개 행정동(읍·면·동)** 및 **47개 시·군·구(31개 시·군)**의 실제 최신 행정경계(`2026.10.01` 기준, 화성시 4개 구·부천시 3개 구 포함) 위에서 시간대별(00:00~23:00)·요일별(평일/주말) 모바일 통신 트래픽 **변화량**을 인터랙티브하게 시각화하는 프로그램입니다.

## 주요 기능

- **최상세 행정경계 시각화**: 경기도 602개 읍·면·동 공유 아크 토폴로지(틈새 없는 정밀 경계) + 서울·인천 배경 실루엣 + 47개 시·군·구 통합 뷰 전환.
- **4가지 변화량/규모 지표 모드**:
  - `변화율 (Δ%)`: 직전 1시간 대비 증감률 (발산형 컬러 스케일: 파랑=감소 / 주황·빨강=급증)
  - `변화량 (Δ Gbps)`: 직전 1시간 대비 절대 증감량
  - `일평균 대비 (%)`: 해당 지역 24시간 평균 대비 현재 시각 편차
  - `총 트래픽 (Gbps)`: 절대 모바일 통신 트래픽 규모
- **시간대 애니메이션 & 탐색**: 60fps 부드러운 시간 보간 재생(`0.5×` / `1.0×` / `2.0×`), 빠른 시간대 프리셋(`03시·08시·12시·15시·18시·21시`), 경기도 전체 24시간 웨이브폼 클릭 점프, 평일/주말 비교.
- **지역 검색 & 상세 분석**: 읍·면·동/시·군·구 즉시 검색 + 부드러운 줌인(Fly-To), 급증/급감 TOP 랭킹, 도시 기능 유형별 평균 변화율, 클릭 시 24시간 트래픽/변화량 이중 차트·5G/LTE 비율·서비스 구성·인근 행정동 비교.
- **실데이터 CSV / JSON 업로드 지원**: 통신사 또는 공공데이터포털·경기데이터드림 등에서 확보한 행정동별 시간대 트래픽 파일을 브라우저에서 즉시 업로드하여 시각화할 수 있습니다.

## 프로젝트 구조

```text
gyeonggi-traffic-map/
├── index.html                        # 완전 자립형 실행 파일 (브라우저에서 바로 열기 가능)
├── src/
│   └── app.html                      # 인터랙티브 Canvas 지도 및 UI 소스 템플릿
├── scripts/
│   ├── build_data.py                 # 602 행정동 공유 아크 추출 + 시공간 트래픽 모델 생성기
│   └── build_app.py                  # 자립형 HTML 번들러
├── data/
│   ├── gyeonggi_bundle.json          # 전처리된 602 행정동 토폴로지 + 트래픽 JSON
│   └── gyeonggi_sample_traffic.csv   # 실데이터 업로드 호환 샘플 CSV (28,896행)
└── raw/
    └── HangJeongDong_ver20261001.geojson  # 대한민국 최신 행정동 원본 경계 (vuski/admdongkor)
```

## 실행 및 재빌드 방법

### 1) 바로 실행
`index.html`을 웹 브라우저로 열거나 로컬 정적 서버로 실행할 수 있습니다.
```bash
python3 -m http.server 8000
```

### 2) 데이터 전처리 및 재빌드
```bash
python3 scripts/build_data.py
python3 scripts/build_app.py
```

## 실데이터 CSV 업로드 형식

`실데이터 업로드` 버튼을 통해 아래 컬럼 구조의 CSV 또는 JSON을 불러올 수 있습니다.

```csv
adm_cd,sggnm,dongnm,day_type,hour,traffic_gbps
4113565500,성남시분당구,삼평동,weekday,8,28.45
4113565500,성남시분당구,삼평동,weekday,9,35.12
```

- `adm_cd` (10자리 또는 8자리 행정동코드) 또는 `sggnm` + `dongnm`으로 자동 매칭됩니다.
- `day_type`은 `weekday`/`weekend` (또는 `평일`/`주말`)을 지원하며, 생략 시 단일 일자 데이터로 반영됩니다.

## 키보드 단축키

- `Space`: 시간대 재생 / 일시정지
- `←` / `→`: 1시간 이전 / 이후 이동
- `+` / `-`: 지도 확대 / 축소
- `R`: 경기도 전체 보기로 리셋
- `Esc`: 선택 지역 해제 / 모달 닫기
