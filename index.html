전국 실시간 API 연동 및 데이터 관리

Cloudflare Worker 프록시(worker/ · 서울 121곳 + 전국 ITS 44권역) 또는 Google Apps Script 웹 앱(gas/Code.gs) URL을 연결하면 실시간 유동인구·혼잡도가 전국 지도에 자동 반영됩니다.

지원 JSON 응답 스키마 보기 (서울 유동인구 · 전국 ITS · 행정동 · 경위도) 
// 1) 실시간 유동인구 · ITS 혼잡도 스냅샷 (gas/Code.gs 기본 출력)
{ "data": [
  { "lon": 127.0276, "lat": 37.4979, "name": "강남역", "source": "seoul_pop", "pop": 58000, "congest": "약간 붐빔", "traffic_gbps": 38.7 },
  { "lon": 129.0596, "lat": 35.1578, "name": "부산 서면·도심", "source": "its", "speed": 24.5, "congest": "정체", "traffic_gbps": 16.4 }
]}
// 2) 행정동별 실시간 스냅샷 (adm_cd 또는 sggnm + dongnm)
{ "data": [ { "adm_cd": "1168064000", "traffic_gbps": 52.4 } ] }

내 Google Drive 스프레드시트(gas/Code.gs)에 누적된 과거 일자별 서울 유동인구 · 전국 ITS 데이터를 불러와 하단 24시간 타임라인으로 그대로 재생·분석합니다.

설치 방법: 저장소의 gas/Code.gs를 Google 스프레드시트 확장 프로그램 → Apps Script에 붙여넣고, gas/README.md 안내대로 트리거·웹 앱을 배포하면 본인 드라이브에 15분마다 자동 누적됩니다.

전국 3,559개 행정동별 시간대 트래픽 CSV/JSON 파일을 업로드하면 해당 행정동과 하위 25,435개 2.1km 셀·800m 초미세 셀에 즉시 비례 반영됩니다.

CSV 또는 JSON 파일을 드래그하거나 클릭하여 선택
지원 컬럼: adm_cd (또는 sggnm, dongnm), hour (0~23), traffic_gbps, day_type
