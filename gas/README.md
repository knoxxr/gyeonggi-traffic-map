# Google Sheets 자동 수집기 & 히스토리 API 설치 가이드

이 스크립트([Code.gs](./Code.gs))를 본인 Google 계정의 스프레드시트에 붙이면, **별도 서버 비용 없이** 15분(또는 10분)마다 아래 데이터를 Google Drive 스프레드시트에 자동 누적하고 웹앱과 바로 연결할 수 있습니다.

- **서울시 실시간 유동인구** (서울 열린데이터광장 `OA-21778` · SKT/KT 기지국 기반 74곳 기본 등록, 121곳까지 시트에서 자유 추가)
- **전국 주요 권역 ITS 실시간 도로 혼잡도** (국가교통정보센터 · 16개 시·도 34개 권역 기본 등록)

---

## 1단계: 무료 API 키 발급 (2곳)

1. **서울 열린데이터광장 인증키** (서울 실시간 유동인구)
   - [인증키 신청 페이지](https://data.seoul.go.kr/together/mypage/actkeyMain.do) 로그인 → 일반 인증키 즉시 발급 (무료)
   - *키 발급 전 테스트만 할 경우 기본값 `sample`로도 광화문·덕수궁 1곳은 바로 동작합니다.*
2. **국가교통정보센터(ITS) 인증키** (전국 실시간 도로 혼잡도)
   - [국가교통정보센터 Open API](https://www.its.go.kr/opendata/opendataList) 로그인 → 인증키 즉시 발급 (무료)

---

## 2단계: Google 스프레드시트에 스크립트 설치

1. Google Drive에서 **새 Google 스프레드시트**를 만듭니다 (예: `한국_유동인구_히스토리`).
2. 상단 메뉴 **`확장 프로그램` → `Apps Script`**를 클릭합니다.
3. 기존 코드를 모두 지우고 [`Code.gs`](./Code.gs) 내용을 그대로 붙여넣은 뒤 **저장(`Ctrl+S`)**합니다.
4. 스프레드시트 탭으로 돌아가 **새로고침(`F5`)**하면 상단 메뉴에 **`📡 트래픽·유동인구 수집기`**가 생깁니다.

---

## 3단계: 초기 설정 & 자동 누적 시작

1. 메뉴 **`📡 트래픽·유동인구 수집기` → `1. 시트 초기 설정`** 클릭 (최초 1회 Google 권한 승인 필요).
   - `설정`, `장소목록`, `최신현황` 탭이 자동 생성됩니다.
2. **`설정`** 탭에서 `SEOUL_API_KEY`와 `ITS_API_KEY` 값을 본인 키로 바꿉니다.
   - *(선택)* `장소목록` 탭에서 원하는 장소만 `Y`/`N`으로 켜거나, 서울시 121장소 목록의 나머지 POI 코드를 행으로 추가할 수 있습니다.
3. 메뉴 **`6. API 키·응답 진단 테스트`** → 정상 확인 후 **`2. 지금 1회 수집 실행`** 클릭.
   - `최신현황` 탭에 현재 가장 붐비는 곳부터 정렬되어 채워지고, `히스토리_YYYYMM` 탭에 누적되기 시작합니다.
4. 메뉴 **`3. 자동 수집 시작 (15분마다)`** 클릭 → 이후 PC를 꺼도 Google 서버에서 24시간 자동 누적됩니다.

> **무료 한도 참고**: 개인 Gmail 계정은 `UrlFetchApp` 일 20,000회까지 무료입니다. 기본 108곳 × 15분 간격(96회/일) = **일 10,368회**로 안전하며, 서울 121곳 전체 + 전국 34곳(155곳)도 15분 간격이면 **일 14,880회**로 무료 한도 내입니다. 월마다 `히스토리_202611`, `히스토리_202612`처럼 시트가 자동 분리되므로 스프레드시트 셀 한도에도 걸리지 않습니다.

## 4단계: 웹 앱 URL 배포 & 지도 앱 연결

1. Apps Script 편집기 우측 상단 **`배포` → `새 배포`** 클릭.
2. 유형: **`웹 앱`** 선택
   - 다음 사용자 권한으로 실행: **`나`**
   - 액세스 권한이 있는 사용자: **`모든 사용자`**
3. **`배포`** 클릭 후 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사합니다.
4. **한국 모바일 트래픽 모니터** 앱에서 상단 **`실시간 API · 데이터`**(모바일: **`API·CSV`**) 클릭:
   - **실시간 보기**: `실시간 API 자동 폴링` 탭에 URL을 붙여넣고 **`실시간 API 폴링 시작`** 클릭.
   - **과거 히스토리 보기**: **`Drive 히스토리`** 탭에서 **`저장된 날짜 조회`** → 날짜 선택 → **`히스토리 불러오기`** 클릭 후 하단 타임라인을 움직이거나 재생(`▶`)합니다.

---

## 지원 API 엔드포인트 (참고)

- 최신 스냅샷: `GET <웹앱URL>?mode=latest`
- 저장된 날짜 목록: `GET <웹앱URL>?mode=dates`
- 특정 날짜 24시간 히스토리: `GET <웹앱URL>?mode=history&date=2026-11-22`
- *(선택)* `설정` 시트에 `허용_토큰`을 입력했다면 요청에 `&token=설정한값`을 추가합니다.
